# 🚢 Titanic Data Analysis

## 📌 Project Description
Titanic Data Analysis is a Python-based project that analyzes passenger data from the Titanic dataset. It uses Pandas, Matplotlib, and Seaborn to explore passenger information, handle missing values, calculate survival rates, and visualize survival patterns.

## ✨ Features

1. **Load Dataset:** Reads Titanic passenger data from a CSV file.
2. **Explore Data:** Displays the first five rows, dataset shape, column names, data types, missing values, and statistical information.
3. **Clean Data:** Fills missing Age values with the median and missing Embarked values with the mode.
4. **Survival Count:** Displays the number of passengers who survived and did not survive.
5. **Survival by Gender:** Compares survival based on gender.
6. **Survival by Passenger Class:** Analyzes survival across passenger classes.
7. **Age Distribution:** Displays the distribution of passenger ages.
8. **Survival Rate:** Calculates the percentage of passengers who survived.
9. **Correlation Heatmap:** Shows correlations between selected numerical features.
10. **Save Cleaned Dataset:** Saves the cleaned data as `cleaned_titanic.csv`.

## ⚙️ Installation

Install the required libraries using the following command:

```bash
python -m pip install pandas matplotlib seaborn
```

## ▶️ How to Run the Project

1. Install Python 3 on your computer.
2. Open the project folder in Visual Studio Code.
3. Ensure the Titanic CSV dataset is available in the same folder as the Python file.
4. Check that the CSV filename in the code matches the actual filename.
5. Open the terminal and run:

```bash
python "project 10.py"
```

6. The program displays dataset information and statistical summaries.
7. View the charts generated by the program.
8. Find the cleaned dataset saved as `cleaned_titanic.csv`.
